- Information in the menu is easier to read: section titles use the standard macOS style, and status and Details lines use the secondary text color.
- Details now update while the menu is open, for example when you put in or remove an AirPod or the audio output changes. The Mono Audio line is now named Accessibility Mono Audio: it shows the macOS Accessibility setting, which MonoPods does not change.
- New Report an Issue… command in the menu opens a new issue on GitHub in your browser. Nothing is sent automatically.
